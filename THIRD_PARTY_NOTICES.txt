Software the user installs separately (not bundled)
---------------------------------------------------
- FSUIPC (Pete & John Dowson) - FSUIPC7 for Microsoft Flight Simulator,
  FSUIPC4/5/6 for Prepar3D and FSX. https://fsuipc.com
  No FSUIPC code or files are included with Flyt ACARS; it talks to the
  user's own FSUIPC installation through FSUIPC's documented IPC
  interface. The free, unregistered version is sufficient.

Online services used (not bundled; each user's own account/IDs)
---------------------------------------------------------------
- SimBrief (Navigraph) - flight plans, fetched with the pilot's own
  SimBrief Pilot ID. https://www.simbrief.com
- VATSIM and IVAO public data feeds - used to check whether the pilot is
  connected, and to show online traffic and ATC on the Live Map.
  https://vatsim.net  -  https://ivao.aero
- GitHub - checking for new releases of this app.
